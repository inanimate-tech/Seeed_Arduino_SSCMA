# Dev-only host memory-safety harness

Compiles the UNMODIFIED library in `../src` against Arduino/Wire/SPI stubs and
real ArduinoJson, and drives it under AddressSanitizer + a fault-injecting
allocator. This directory exists only on the `fix/memory-safety` branch to
prove the src/ fixes; it is intentionally NOT part of the upstream library.

Run:  `make test`   (fetches ArduinoJson on first run)
